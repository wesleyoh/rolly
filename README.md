# Rolly (또르르 / コロリン)

Draw one line, roll the ball into the cup. Daily puzzles + 100+ stages.

- Game code: `www/` (plain HTML/CSS/JS, no build step)
- Native wrapper: Capacitor 8 (`ios/`, `android/`)
- iOS CI: `.github/workflows/ios-testflight.yml`
- Launch plan (Korean): `LAUNCH.md`
- Store screenshots: `store/screens/`
- Privacy policy: `docs/privacy.html`

```
npm ci
npx cap sync
```
